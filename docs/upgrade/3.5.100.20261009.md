## 破坏性变更（breaking changes）

##### redisson 3.43.0 -> 4.8.0

* refactor: 移除 `getNodesGroup` / `getClusterNodesGroup`（redisson 4 删除该 API，改用 `getRedisNodes(RedisNodes)`），
  `DynamicRedissonClient` / `DynamicAopRedissonClient` 同步移除
* refactor: `Config.fromJSON(String)` 已删除，新增兼容层 `RedissonConfigCompat`：JSON/YAML 统一走 `Config.fromYAML`，自动提取
  `codec.class` 提示并反射注入
* refactor: YAML 不再支持 `codec: { class: fqcn }` 嵌套提示（snakeyaml 直接 bean 绑定）
* fix: 示例配置 codec 由 `org.redisson.codec.JsonJacksonCodec` 改为 `org.redisson.codec.SerializationCodec`（redisson 4 将
  jackson 拆为 provided/optional，开箱不可用）
* fix: `DynamicAopRedissonClient#getBoundedBlockingQueue/getDeque` 递归自调用 `StackOverflowError` 修复，改为正确委托底层
  `RedissonClient`（此前调用即不可用）

##### okhttp 4 -> 5

* refactor: 统一使用 `com.squareup.okhttp3:okhttp-jvm` 坐标（okhttp 5 的 `okhttp` 构件为 Gradle 模块壳，无 class）
* refactor: `feign-okhttp` 排除 okhttp 4 传递依赖，显式引入 `okhttp-jvm:5.5.0`
* note: okhttp 4 的部分 API 在 5 中有位置调整；feign 桥接层不受影响（已通过运行时探针验证）

##### mybatis-plus 3.5.7 -> 3.5.17

* refactor: `MybatisSqlSessionFactoryBean` 包迁移 `com.baomidou.mybatisplus.extension.spring` ->
  `com.baomidou.mybatisplus.spring`（新构件 mybatis-plus-spring），`MybatisPlusCommonAutoConfiguration` /
  `MybatisPlusIdAutoConfiguration` / `MybatisPlusNoIdAutoConfiguration` 已适配
* refactor: `executeBatch` / `saveOrUpdateBatch` 回调签名变更 `BiFunction<SqlSession, E, Boolean>` ->
  `BiFunction<SqlSession, E, Integer>`，`SuperRepositoryImpl` 已适配
* fix: `SuperRepositoryImpl#saveOrUpdateBatch` 改用虚分派 `getSqlSessionFactory()`，Repository 子类覆写工厂现在生效 （此前
  `super.` 调用绕过覆写）

##### spring boot 3.5 API 变更

* fix: `PropertiesMongoConnectionDetails` 新增 `SslBundles` 参数，`DynamicMongoClient` 已适配
* fix: `StandardMongoClientSettingsBuilderCustomizer` 4 参构造器 `@Deprecated(forRemoval)`（since 3.5.0），改用 2 参
  `(connectionDetails, uuidRepresentation)`
* fix: Lettuce 连接池泛型收紧 `GenericObjectPoolConfig<LettuceConnection>` ->
  `GenericObjectPoolConfig<StatefulConnection<?, ?>>`

## 质量加固（本版本新增）

### 1. 覆盖率构建门禁（对 fork 构建者是 breaking change）

根 pom 的 jacoco 插件在 `verify` 阶段新增 `coverage-check` 规则：

* 每个含代码模块强制 `LINE` 与 `BRANCH` 覆盖率 `COVEREDRATIO >= 1.00`
* **已移除全部 excludes**（原 `**/example/**`、`**/*$Builder*` 均不再排除）
* 后果：任何模块覆盖率不达标，`mvn verify` 直接构建失败

迁移动作：

* fork 本仓库构建的使用方：新增/修改代码必须同步补齐单测
* 仅使用发布制品（maven 坐标引入）的使用方 **不受影响**

### 2. 测试范围新增依赖（仅影响源码构建，不传递到使用方制品）

| 模块                        | 新增 test 依赖                        | 原因                                                                                                                    |
|-----------------------------|---------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| components-util-extra       | commons-logging 1.2                   | pdfbox 日志门面                                                                                                         |
| components-util-compression | org.tukaani:xz 1.9                    | 7z/xz 压缩格式测试                                                                                                      |
| components-starter-mongodb  | mongodb-driver-reactivestreams 5.13.0 | `TransactionManagerAutoConfiguration` 方法体需加载响应式类（生产环境仍由 `@ConditionalOnClass` 控制，无驱动时自动跳过） |
| components-starter-mongodb  | spring-jdbc                           | Morphia 注解扫描需解析引用类                                                                                            |
| components-starters（父）   | spring-boot-starter-test              | 统一 JUnit4/Mockito/MockMvc 基础设施                                                                                    |

### 3. 等价重构 —— 零迁移成本

约 40 处源码重构均为 **不可达防御分支删除/死代码清理**（枚举 switch 合成 default、 getBean/getAnnotationsByType 返回值后的
null 检查、标准 JVM 下不可能抛出的 checked 异常 catch 等），已逐条验证行为等价，无 API 签名变化、无行为变化：

* trim：`TrimParse` switch 改 if-else
* annotation：`ProcessorContainerConfiguration` / `AccessLimit` / `ServiceLock` 拦截器 /
  `PrivacyInfoAnnotationInterceptor` 等删除不可达 null 检查
* redis：`MultiRedisson` / `DynamicRedisConnectionFactory` / `FastJsonRedisTemplate` 删除死代码与不可达分支
* feign：`FeignAutoScanConfiguration` / `UseLocalFeignClientCondition` / `OkHttpAutoConfiguration` 等
* media / object-storage：Builder 恒真判断、重复 key 不可达抛出分支等

## 迁移步骤清单（TL;DR）

1. 升级 maven 坐标至 `3.5.100.20261009-RELEASE`

7. fork 构建者：为覆盖率门禁补齐测试；制品使用方无其他变更

## 破坏性变更（breaking changes）

##### redisson 3.43.0 -> 4.8.0

* refactor: 移除 `getNodesGroup` / `getClusterNodesGroup`（redisson 4 删除该 API，改用 `getRedisNodes(RedisNodes)`），
  `DynamicRedissonClient` / `DynamicAopRedissonClient` 同步移除
* refactor: `Config.fromJSON(String)` 已删除（redisson 4 仅保留 `Config.fromYAML`），组件同步移除 JSON 配置支持：
  `GlobalRedissonProperties.configJsonStr` 与 `DynamicRedissonProperties.Config.configJsonStr` 属性 **已删除**
  （配置文件中残留 `config-json-str` 键将被忽略，请迁移为 `config-yaml-str`），仅支持 `config-file` /
  `config-yaml-str`（YAML）；YAML 也不再支持 `codec: { class: fqcn }` 嵌套提示（snakeyaml 直接 bean 绑定），
  codec 请通过 `codec`（顶层 bean 属性）或代码方式设置
* note: codec 配置说明——redisson 4 将 jackson 依赖拆为 provided/optional（不再传递），但
  `org.redisson.codec.JsonJacksonCodec` 类本身仍在 redisson jar 中， **配置它依然可用**：使用方工程自带
  jackson（Spring Boot Web 场景必然有）时无需任何改动；仅无 jackson 依赖的极简工程会在 codec 实例化时抛
  `NoClassDefFoundError`，此时自行引入 `jackson-databind` 或改用 `SerializationCodec` 即可。
  组件示例配置使用 `JsonJacksonCodec`（示例工程经 components-starter-web 携带 jackson）；
  redisson 4 的 YAML 中 codec 需使用全局 tag 写法：
  `codec: !<tag:yaml.org,2002:org.redisson.codec.JsonJacksonCodec> {}`（旧的 `codec: { class: fqcn }` 嵌套写法不再支持）
* fix: `DynamicAopRedissonClient#getBoundedBlockingQueue/getDeque` 递归自调用 `StackOverflowError` 修复，改为正确委托底层
  `RedissonClient`（此前调用即不可用）

##### okhttp 4 -> 5

* refactor: 统一使用 `com.squareup.okhttp3:okhttp-jvm` 坐标（okhttp 5 的 `okhttp` 构件为 Gradle 模块壳，无 class）
* refactor: `feign-okhttp` 排除 okhttp 4 传递依赖，显式引入 `okhttp-jvm:5.5.0`
* note: okhttp 4 的部分 API 在 5 中有位置调整；feign 桥接层不受影响（已通过运行时探针验证）

##### mybatis-plus 3.5.7 -> 3.5.17

* refactor: `MybatisSqlSessionFactoryBean` 包迁移 `com.baomidou.mybatisplus.extension.spring` ->
  `com.baomidou.mybatisplus.spring`（新构件 mybatis-plus-spring），`MybatisPlusCommonAutoConfiguration` /
  `MybatisPlusIdAutoConfiguration` / `MybatisPlusNoIdAutoConfiguration` 已适配
* refactor: `executeBatch` / `saveOrUpdateBatch` 回调签名变更 `BiFunction<SqlSession, E, Boolean>` ->
  `BiFunction<SqlSession, E, Integer>`，`SuperRepositoryImpl` 已适配
* fix: `SuperRepositoryImpl#saveOrUpdateBatch` 改用虚分派 `getSqlSessionFactory()`，Repository 子类覆写工厂现在生效 （此前
  `super.` 调用绕过覆写）

##### spring boot 3.5 API 变更

* fix: `PropertiesMongoConnectionDetails` 新增 `SslBundles` 参数，`DynamicMongoClient` 已适配
* fix: `StandardMongoClientSettingsBuilderCustomizer` 4 参构造器 `@Deprecated(forRemoval)`（since 3.5.0），改用 2 参
  `(connectionDetails, uuidRepresentation)`
* fix: Lettuce 连接池泛型收紧 `GenericObjectPoolConfig<LettuceConnection>` ->
  `GenericObjectPoolConfig<StatefulConnection<?, ?>>`

## 迁移步骤清单（TL;DR）

1. 升级 maven 坐标至 `3.5.1.20261029-RELEASE`
2. **redisson 4 适配**：`config-json-str` 配置属性已删除（残留键被忽略、不再生效），迁移为
   `config-yaml-str`（YAML）；redisson YAML 内的 codec 配置写法变更，旧的嵌套写法
   `codec: { class: "fqcn" }` 不再支持（解析报错），改为全局 tag 写法：
   `codec: !<tag:yaml.org,2002:org.redisson.codec.JsonJacksonCodec> {}`
3. **spring.redis → spring.data.redis 属性迁移**：Spring Boot 3.x 起 Redis 配置前缀由
   `spring.redis` 迁移至 `spring.data.redis`（Boot 2.x 升 3.x 的既有变更，本次升级一并确认），
   使用方工程 `application.yml` 中的 `spring.redis.*`（host/port/password/database/lettuce/jedis 等）
   需整体改为 `spring.data.redis.*`，旧前缀不再生效
4. **okhttp 5 适配**：工程内若有直引 okhttp 4 坐标，改为 `okhttp-jvm:5.5.0`
5. **mybatis-plus 3.5.17 适配**：直接 import `MybatisSqlSessionFactoryBean` 的代码改新包
   `com.baomidou.mybatisplus.spring`；`executeBatch/saveOrUpdateBatch` 回调返回值改为 `Integer`
6. **javax → jakarta 命名空间迁移**：Spring Boot 3.5 全系基于 jakarta 命名空间，使用方工程内直接依赖
   javax API 的代码需同步迁移：
    * `javax.servlet.*` → `jakarta.servlet.*`（Filter/Listener/HttpServletRequest 等）
    * `javax.validation.*` → `jakarta.validation.*`（`@NotNull`/`@Valid` 等）
    * `javax.annotation.*` → `jakarta.annotation.*`（`@PostConstruct`/`@Resource` 等）
    * `javax.persistence.*` → `jakarta.persistence.*`（JPA 注解，如使用）

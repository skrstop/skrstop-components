## 破坏性变更（breaking changes）

##### redisson 3.43.0 -> 4.8.0

* refactor: 移除 `getNodesGroup` / `getClusterNodesGroup`（redisson 4 删除该 API，改用 `getRedisNodes(RedisNodes)`），
  `DynamicRedissonClient` / `DynamicAopRedissonClient` 同步移除
* refactor: `Config.fromJSON(String)` 已删除，新增兼容层 `RedissonConfigCompat`：JSON/YAML 统一走 `Config.fromYAML`，自动提取
  `codec.class` 提示并反射注入
* refactor: YAML 不再支持 `codec: { class: fqcn }` 嵌套提示（snakeyaml 直接 bean 绑定）
* fix: 示例配置 codec 由 `org.redisson.codec.JsonJacksonCodec` 改为 `org.redisson.codec.SerializationCodec`（redisson 4 将
  jackson 拆为 provided/optional，开箱不可用）

##### okhttp 4 -> 5

* refactor: 统一使用 `com.squareup.okhttp3:okhttp-jvm` 坐标（okhttp 5 的 `okhttp` 构件为 Gradle 模块壳，无 class）
* refactor: `feign-okhttp` 排除 okhttp 4 传递依赖，显式引入 `okhttp-jvm:5.5.0`
* note: okhttp 4 的部分 API 在 5 中有位置调整；feign 桥接层不受影响（已通过运行时探针验证）

##### mybatis-plus 3.5.7 -> 3.5.17

* refactor: `MybatisSqlSessionFactoryBean` 包迁移 `com.baomidou.mybatisplus.extension.spring` ->
  `com.baomidou.mybatisplus.spring`（新构件 mybatis-plus-spring），`MybatisPlusCommonAutoConfiguration` /
  `MybatisPlusIdAutoConfiguration` / `MybatisPlusNoIdAutoConfiguration` 已适配
* refactor: `executeBatch` / `saveOrUpdateBatch` 回调签名变更 `BiFunction<SqlSession, E, Boolean>` ->
  `BiFunction<SqlSession, E, Integer>`，`SuperRepositoryImpl` 已适配

##### spring boot 3.5 API 变更

* fix: `PropertiesMongoConnectionDetails` 新增 `SslBundles` 参数，`DynamicMongoClient` 已适配
* fix: `StandardMongoClientSettingsBuilderCustomizer` 4 参构造器 `@Deprecated(forRemoval)`（since 3.5.0），改用 2 参
  `(connectionDetails, uuidRepresentation)`
* fix: Lettuce 连接池泛型收紧 `GenericObjectPoolConfig<LettuceConnection>` ->
  `GenericObjectPoolConfig<StatefulConnection<?, ?>>`
